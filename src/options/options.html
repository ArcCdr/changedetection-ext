ChangeDetection.io Monitor

The address you open changedetection.io at.
In changedetection.io: Settings → API.

Setup

  1. In changedetection.io, open Settings → API and copy the API key.
  2. Enter the server URL and API key, then click Test connection.
  3. Click Save. Chrome asks once for access to your server.

Requires changedetection.io 0.50.12 or newer.
